# ☁️ Stamarc Cloud

> Sistema de almacenamiento en la nube personal desarrollado por **Stamarc Studios**.

## 🚀 Sobre el proyecto
**Stamarc Cloud** es una interfaz web moderna y minimalista diseñada para la gestión, organización y previsualización de archivos en la nube. Este proyecto forma parte de las soluciones tecnológicas creadas bajo la identidad de Stamarc Studios.

## ✨ Características principales
- **Interfaz moderna:** Diseñada con Tailwind CSS en modo oscuro.
- **Subida intuitiva (Drag & Drop):** Arrastra y suelta archivos con simulación de barra de progreso.
- **Filtros por categorías:** Organiza fácilmente tus imágenes, documentos y archivos multimedia.
- **Previsualización de archivos:** Visualiza tus imágenes y detalles de tus archivos al instante.
- **Buscador integrado:** Filtra tus archivos en tiempo real por su nombre.
- **Indicador de almacenamiento:** Muestra el espacio utilizado en tu servidor.

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **JavaScript Vanilla** (Lógica de la interfaz y manejo de archivos)
- **Tailwind CSS** (Diseño y estilos)
- **Lucide Icons** (Iconografía)
